# The Funniest Toaster Error Message

The funniest error message a kitchen toaster would show its owner — for the make.fun bounty "The Funniest Toaster Error Message".

## Entry

> Error 402: bread is a rumor. I refuse to participate further.

## How it works

`main.py` (Python 3, stdlib only) writes the single error line to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (default `out`), with no trailing newline. Run it with:

```sh
python3 main.py
```
